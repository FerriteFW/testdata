# Provenance

Every file group of Ferrite's test data: where it came from, its licence, and whether it is in this repository.
"Fetch" means a script in `fetch/` downloads it from its source; "private" means it stays only in Ferrite's private
test-data repo.

| Path | Source | Licence | Public | Why |
| --- | --- | --- | --- | --- |
| `aprs/spec.hex`, `aprs/spec.jsonl` | 64 packets we wrote from the APRS Protocol Reference 1.0.1 and the 1.1/1.2 addenda (Ferrite's `digimodes/uaprs/tests/spec_packets.txt`), hex-encoded; `.jsonl` is Ham::APRS::FAP 1.21's parse of each | Ours (PolyForm NC); several packets follow the spec's examples, whose terms allow non-commercial copying with the spec's copyright and trademark statements (in `LICENSE.md`) | yes | Our work; the spec's terms allow it for non-commercial use with its notice |
| `aprs/suite.hex`, `aprs/suite.jsonl` | 14 packet literals extracted from Ham::APRS::FAP 1.21's `t/*.t` test suite (CPAN); `.jsonl` is FAP's parse | Same terms as Perl (Artistic or GPL), Tapio Sokura and Heikki Hannikainen | yes | The licence allows redistribution; notice in `LICENSE.md` |
| `aprs/fap.version` | The FAP version used | Ours | yes | Ours |
| `aprs/Ham-APRS-FAP-1.21.tar.gz`, `aprs/Ham-APRS-FAP-1.21/` | CPAN | Same terms as Perl | fetch (`fetch/ham-aprs-fap.sh`) | A Perl library, not test data: fetch from CPAN rather than copy |

## Not public yet

- The Burlington APRS recordings: public only if whoever made them confirms it (they hold third parties' traffic,
  which amateur rules allow anyone to receive; the question is only who recorded them).
- The K1VL WSPR recordings: public only with the KiwiSDR owner's permission.
